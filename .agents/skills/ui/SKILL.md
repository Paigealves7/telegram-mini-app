# UI Redesign Skill
Когда пользователь вызывает `/ui`:
1. Работай ТОЛЬКО с файлом `web/index.html`. Не читай никакие другие файлы проекта.
2. Соблюдай премиальный мобильный стиль Dark Glass:
   - Чёткая сетка отступов, крупные скругленные карточки, стеклянные панели (`backdrop-filter`), удобное нажатие одной рукой на телефоне.
   - Плоские строки списков заменяй на читаемые карточки с крупными цифрами кубатуры (`м³`) и сумм (`₽`), статусы показывай аккуратными цветными капсулами (badges).
3. Строго сохраняй все существующие атрибуты `data-a`, `data-v`, `data-k`, `id` элементов и JS-обработчики в `ACT` и `FORMS`, чтобы не нарушить работу приложения.

## Правила микро-интеракций и полировки (Emil Kowalski + Impeccable Harden)

- Анимируй только `transform` и `opacity`. Не анимируй `height`, `width`, `top`, `left` и `margin`.
- Для шторок, модалок и тостов используй `cubic-bezier(0.22, 1, 0.36, 1)` или `var(--ease)`. Вход — 180–260 ms, выход быстрее на 20–30% — 140–180 ms.
- Для тактильного отклика применяй `:active { transform: scale(0.97) }` с длительностью 100 ms. Учитывай `html.lite` и `prefers-reduced-motion: reduce`.
- Не отрывай единицы `м³`, `шт` и `₽` от чисел. Используй `white-space: nowrap`.
- Во Flex/Grid-контейнерах с текстом применяй `min-width: 0` и `overflow-wrap: anywhere` или `text-overflow: ellipsis` для экранов от 320 px.
- Проверяй контраст рамок и карточек в темах `dark` и `light` в стиле `Flowstate / Lumber`.
