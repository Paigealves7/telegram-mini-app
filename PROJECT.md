# PROJECT.md — Состояние проекта «Лесопилка» (Sawmill Mini App)

## 1. О продукте и окружении
- **Продукт:** Telegram Mini App + веб-версия для полного учёта лесопилки (приход сырья, распил на доски, учёт дров, склад, заявки, оплаты, долги клиентов, PDF-накладные, аналитика).
- **Продакшен:** `https://sawmill.urmanit.ru:8808` (сервер по SSH: `ssh sawmill`, папка `~/apps/telegram-mini-app`, контейнеры `sawmill_app` и `sawmill_db`).
- **Текущая версия БД:** Применены миграции `000001` — `000010` включительно.

## 2. Что реализовано (Done)
- **Авторизация и роли:** Вход через Telegram (`initData`) и по логину/паролю (JWT). Три роли: `manager` (Руководитель), `master` (Мастер), `worker` (Сотрудник).
- **Учёт леса и пиломатериалов:** Приход брёвен по партиям, распиловка (с контролем выхода), склад досок и брёвен, журнал корректировок склада.
- **Учёт дров (миграции 000008 и 000009):**
  - Приход берёзовых дров общей кубатурой (`firewood_arrivals`).
  - Переработка от готового объёма (`split` — колотые с коэф. `0.55`, `round` — чурбаки с коэф. `0.60`), настраиваемые коэффициенты (`firewood_settings`).
  - Склад сырья дров и готовых дров, добавление дров в заявки и в PDF-накладную.
- **Заказы, продажи и финансы:** Создание и завершение заявок, частичные оплаты, учёт долгов клиентов, генерация PDF-накладных с суммой прописью и отправкой в бот.

### Реализовано в ветке `audit-fixes` — 18.11.2026

- **Статусы заказов:** руководитель и мастер могут взять новый заказ в работу и отменить открытый заказ. Отмена блокируется при наличии принятых оплат.
- **Единая корзина:** несколько складских позиций досок и видов готовых дров в одном заказе, с проверкой суммарных остатков, доставкой и дополнительными услугами.
- **Приход леса:** несколько позиций на машину, табличная кубатура по ГОСТ 2708-75, оценка по сбегу для нестандартных размеров и ручной ввод объёма.
- **Отчёты:** объём выпуска, средний выход пиломатериала и потери за период. Выпуск восстанавливается по остатку, продажам и корректировкам складских партий.
- Проверено через `go build ./...`, `go test ./internal/...`, в Chromium с тестовым API и на отдельной PostgreSQL 15.

### Супер-админ — 18.11.2026

- Аккаунт с ID `2` или логином `tg_1157708667` получает права супер-админа. Дополнительные ID и логины задаются через `SUPER_ADMIN_IDS`. Доступ проверяется по актуальной записи пользователя при каждом запросе.
- Супер-админ управляет всеми тремя ролями и удаляет других сотрудников с сохранением истории операций. Удалённый Telegram-аккаунт теряет доступ и исключается из автоматической регистрации.
- Из карточек можно удалить заказ, приход леса или дров, распил и прямую продажу. Списание склада отменяется в транзакции. Удаление блокируется, если товар уже использован в зависимых операциях или у старого завершённого заказа отсутствует однозначная связь с продажей.
- Позиции досок и остатки сырья, колотых дров и чурбаков редактируются на складе. Корректировки объёмов сохраняются в БД.
- Миграция `000010_super_admin_stock.up.sql` применена на сервере. Изменения супер-админа проверены через `go build ./...`, HTTP на отдельной PostgreSQL 15 и Chromium на 390 и 1440 px.

### Telegram Bot API и товарная накладная

- `TELEGRAM_PROXY` задаёт HTTP(S) или SOCKS5/SOCKS5H-прокси для `getMe`, уведомлений и отправки PDF. `TELEGRAM_API_BASE` задаёт адрес Bot API и по умолчанию указывает на `https://api.telegram.org`.
- Товарная накладная включает реквизиты сторон, основание и имя ответственного, семь колонок товаров, итоги с оплатами и долгом, сумму прописью и поля для подписей, должностей и печати.

### Подтверждение доступа и очистка тестовых данных

- Новые Telegram-аккаунты получают роль `pending` до одобрения руководителем. Настроенные супер-админы сразу получают доступ. Ранее созданные аккаунты сохраняют свои роли.
- Сброс доступен супер-админу в карточке демонстрационной лесопилки в `/admin` после ввода слова «СБРОС». Он удаляет операционные данные лесопилки, включая оплаты и корректировки дров, и начинает нумерацию заказов с №1. Сотрудники, контрагенты и коэффициенты сохраняются.
- PDF-ссылки привязаны к дате создания заказа. Ссылки прежнего формата нужно выпустить заново.
- Перед запуском этой версии на существующей БД применить `000011_pending_role.up.sql`. На пустой БД Compose выполнит миграцию при инициализации.

### Мульти-тенантность

- Основной бот и одна база обслуживают несколько лесопилок. Миграция `000012` привязывает существующие операции и сотрудников к организации «Лесопилка». Данные склада, заказов, оплат и долгов разделены по организациям.
- Пользователь работает в выбранной организации с ролью из её состава. При доступе к нескольким лесопилкам переключатель доступен по названию на Главной и в профиле. При смене лесопилки интерфейс очищает кэш и игнорирует ответы предыдущих запросов.
- Руководитель выдаёт и отзывает коды приглашения. Сотрудник вводит код в приложении или открывает Telegram Mini App с параметром `startapp=inv_<код>`. Супер-админ управляет организациями и выдаёт приглашения руководителям.
- Заказы, уведомления и PDF используют номер внутри организации. Накладная подставляет название и реквизиты лесопилки.
- Демо-сброс требует подтверждения и доступен супер-админу. Он удаляет операции и обнуляет счётчик заказов только в выбранной демонстрационной организации.

### Панель управления платформой — 19.11.2026

- В `/admin` супер-админ видит состояние сервиса, метрики БД и лесопилок, управляет реквизитами, статусами, приглашениями и демо-сбросом. Из карточки лесопилки можно открыть склад с предпросмотром интерфейса любой рабочей роли.
- `ADMIN_BOT_TOKEN` позволяет входить через второго Telegram-бота. Для него укажите URL Mini App с путём `/admin` в BotFather. Приглашения сотрудников ведут в основной бот.

### Учёт брёвен по партиям — 21.11.2026

- Приход объединяет в одну позицию брёвна одинаковой породы, длины и диаметра. Склад показывает остаток по партии, породе и длине, а в шторке раскрывает диаметры и исходные позиции для корректировки.
- Распиловка списывает введённый объём из выбранной партии по возрастанию ID позиций. Один распил может выпускать доски нескольких размеров. Предпросмотр показывает суммарную кубатуру и процент выхода.
- Проверено через Go-сборку и тесты, проверку синтаксиса JS и Chromium с тестовым API на 375, 390, 1280 и 1440 px в обеих темах.

### Веб-доступ сотрудников — 21.11.2026

- Супер-админ создаёт веб-аккаунт в карточке лесопилки, копирует данные для входа, меняет пароли и удаляет членство. Один аккаунт может работать в нескольких лесопилках с общим паролем и отдельной ролью в каждой.
- На экране входа можно активировать приглашение и сразу открыть склад нужной лесопилки. Действующий аккаунт подключает новую лесопилку по коду с текущим паролем либо из профиля после входа.
- Сборка, тесты Go и синтаксис JS проверены. Оба сценария входа прошли в Chromium с локальным Go API и отдельной PostgreSQL. Миграции для веб-доступа не требуются.

### Навигация, склад и приглашения — 22.11.2026

### Подписка и демо-стенд в ветке `multi-tenant` — 22.11.2026
